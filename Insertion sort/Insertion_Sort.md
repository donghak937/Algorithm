# Insertion Sort (삽입 정렬)

삽입 정렬은 각 숫자를 적절한 위치에 '삽입'하는 정렬 방법입니다. 데이터를 하나씩 확인하며, 이미 정렬된 부분과 비교하여 자신의 위치를 찾아 삽입함으로써 정렬을 완성합니다. 필요할 때만 위치를 바꾸므로 데이터가 거의 정렬되어 있을 때 매우 효율적입니다.

### 1. 핵심 특징
- **시간 복잡도 (Time Complexity):** 
  - 평균 및 최악의 경우: **O(N²)** (데이터가 역순으로 정렬된 경우)
  - 최선의 경우: **O(N)** (이미 정렬되어 있는 경우)
- **공간 복잡도 (Space Complexity):** **O(1)** (추가적인 배열 공간이 필요없는 In-place 정렬)
- **안정성 (Stability):** **안정 정렬 (Stable Sort)** (동일한 값의 데이터의 상대적인 순서가 유지됨)

### 2. 작동 원리
1. 두 번째 데이터부터 시작합니다. (첫 번째 데이터는 그 자체로 정렬되어 있다고 가정합니다.)
2. 현재 위치의 원소를 변수(`key`)에 저장하고, 이전에 위치한 부분 배열의 원소들과 비교합니다.
3. 이전 원소가 `key`보다 크다면, 이전 원소를 한 칸 뒤로 이동시킵니다.
4. 더 작은 원소를 만나거나 배열의 맨 앞에 도달하면, 그 위치에 `key`를 삽입합니다.
5. 이 과정을 전체 배열이 정렬될 때까지 반복합니다.

### 3. 예시 코드 (C++)
```cpp
#include <iostream>
#include <vector>

using namespace std;

void insertionSort(vector<int>& arr) {
    int n = arr.size();
    // 두 번째 원소부터 끝까지 탐색합니다.
    for (int i = 1; i < n; i++) {
        int key = arr[i]; // 현재 정렬할 타겟 요소
        int j = i - 1;

        // key보다 큰 원소를 한 칸씩 뒤로 이동시킵니다.
        // 앞부분은 이미 늘 정렬되어 있으므로, key보다 작거나 같은 값을 만나면 반복을 멈춥니다.
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        // 찾은 위치(j의 다음 위치)에 key를 삽입합니다.
        arr[j + 1] = key;
    }
}
 
int main() {
    vector<int> arr = {64, 25, 12, 22, 11};
    
    cout << "정렬 전: ";
    for (int x : arr) cout << x << " ";
    cout << "\n";
    
    insertionSort(arr);
    
    cout << "정렬 후: ";
    for (int x : arr) cout << x << " ";
    cout << "\n";
    
    return 0;
}
```

### 4. 장단점
- **장점:** 
  - 알고리즘 구조가 단순하고 구현하기 쉽습니다.
  - 리스트가 이미 정렬되어 있거나 어느 정도 정렬된 상태일 때 다른 `O(N²)` 정렬(선택 정렬, 버블 정렬)보다 더 효율적이고 빠릅니다.
- **단점:** 
  - 배열의 크기가 클 경우 시간 복잡도가 `O(N²)`이므로 효율성이 극히 떨어집니다.
